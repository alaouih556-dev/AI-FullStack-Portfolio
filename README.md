# Abdelhamid Alaoui — Recruiter-focused Portfolio

A fully responsive, bilingual (English/French), static portfolio with interactive project filters and case study dialogs. No install, API key, or build system required.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish on Vercel
Create a new project, upload this folder via a Git repository, select **Other** as Framework Preset, leave the Build Command empty, and set Output Directory to `.` (or default where appropriate). Alternatively deploy to Netlify via drag and drop.

## REQUIRED before publishing
1. Replace empty `CONFIG.email` in `index.html` with your real professional email. Current contact links open a draft without a recipient to avoid publishing a fake email.
2. Set `CONFIG.linkedin` to your exact personal LinkedIn URL.
3. Verify diploma's exact official title and institution (the site notes that wording is to be verified).
4. Verify official names and dates of Tamheen/CTPES/GIZ certificates.
5. Verify the scope of personal contribution and which features shipped vs prototype before making public claims.
6. Add real, approved screenshots, verified repo links and a PDF CV. Existing visual panels are intentionally abstract, **not** misleading screenshots.
7. Check ownership/confidentiality of code and internal client projects before publishing GitHub repos.
